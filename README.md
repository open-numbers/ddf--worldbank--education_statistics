# World Bank Education Statistics

This dataset contains education statistics from the World Bank DataBank, covering 3,665 indicators across 242 countries and regions from 1970 to 2100 (including projections).

To get started with DDF and learn how to use the dataset, please read the
[introduction to DDF][1] and [DDFcsv format document][2].

[1]: https://open-numbers.github.io/ddf.html
[2]: https://docs.google.com/document/d/1aynARjsrSgOKsO1dEqboTqANRD1O9u7J_xmxy8m5jW8

## Indicators

See [`ddf--concepts.csv`](ddf--concepts.csv) for the full list of indicators with metadata including definitions, units of measurement, and sources.

## Definition of indicator

Indicator definitions are included in the `short_definition` and `long_definition` columns of [`ddf--concepts.csv`](ddf--concepts.csv).

## Unit of measurement

Units of measurement are included in the `unit_of_measure` column of [`ddf--concepts.csv`](ddf--concepts.csv).

## Data sources summary

World Bank Education Statistics (EdStats):
https://databank.worldbank.org/source/education-statistics-%5e-all-indicators

## Specific information about this indicator

See the `source`, `statistical_concept_and_methodology`, and `limitations_and_exceptions` columns in [`ddf--concepts.csv`](ddf--concepts.csv) for detailed information about each indicator.
